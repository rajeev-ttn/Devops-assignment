What this assignment shows

DevOps joins development and operations so software can be built, tested, and released in a repeatable way. The ideas below are the pieces most pipelines use.

Source control

Code lives in Git. A new commit is the starting point for the pipeline.

Automated checks

Tests and a build run on every change, so broken code is caught early.

Release

A successful build is packaged and deployed to an environment such as staging or production.

CI/CD pipeline

A CI/CD pipeline is the automated path from a code change to a running application. CI means Continuous Integration. CD means Continuous Delivery or Continuous Deployment.

In Continuous Integration, people merge code into a shared repository often. Each change is built and tested automatically.

In Continuous Delivery, a change that passes those checks is ready to release. In Continuous Deployment, that release is sent out automatically.
