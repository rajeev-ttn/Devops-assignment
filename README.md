# DevOps Assignment Demo

A one-page demo with a CI/CD explanation and a button that walks through commit, test, build, and deploy.

Open `index.html` in a browser.

## Deploy

`.github/workflows/deploy.yml` publishes this page to GitHub Pages on every push to `main`.

In the repository, open **Settings → Pages** and set the source to **GitHub Actions**. The site URL appears on the workflow run after the deploy job finishes.
